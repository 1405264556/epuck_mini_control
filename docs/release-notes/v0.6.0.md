## 下载与使用

1. 下载下方 `epuck_mini_control-v0.6.0-win64.zip`，**完整解压**整个 `epuck_mini_control` 文件夹。
2. 双击 `启动 e-puck Mini.cmd` 或 `epuck_mini_control.exe`。不需要安装 Qt 或其他运行库。
3. 机器人开机并在 Windows 里完成蓝牙配对 → 点 **扫描设备** → **双击设备**连接。
4. 拖动摇杆或按 **W A S D** 驾驶，**空格**停止，**Esc** 急停。

详细操作见 [README](https://github.com/1405264556/epuck_mini_control#readme)。

## 主要变化

**连接**
- 蓝牙掉线后自动重连（1、2、4 秒间隔，默认 3 次，可在设置里调整）。
- 能识别“串口没报错但机器人不应答”的假死链路，约 5~6 秒后判定掉线并重连。
- 记住连接过的设备，下次启动不用重新扫描；可选启动时自动连接。
- 关闭程序不再可能卡住，退出前先给机器人发停止指令。

**控制**
- 键盘驾驶 W A S D，可组合走弧线；单机驾驶选中的机器人，多机驾驶同步组。
- 摇杆随面板缩放，带死区和可调限速。
- 修复：切到其他窗口时现在会真正停车（0.5.0 中这项保护没有生效）。
- 急停按钮固定在工具栏右侧，始终可见。

**界面**
- 统一图标和样式，修复数字框、下拉框的箭头。
- 设备列表显示端口和状态，双击连接，右键可移除或手动输入端口。
- 地图可拖动平移、双击适应全部；点击机器人只选中，不再误移位置。
- 小窗口（1024×720）下驾驶面板完整可见；原始数据表可以正常滚动。

完整列表见 [CHANGELOG](https://github.com/1405264556/epuck_mini_control/blob/main/CHANGELOG.md)。

## 请注意

- 这个版本的连接和控制逻辑是用**模拟机器人**测试的，还没有在真实 e-puck Mini 上验证。第一次使用请把机器人架起来或放在空旷场地低速试。
- 真实蓝牙端口掉线后恢复所需的时间可能比默认的重连窗口长，反复重连失败时请在“文件 / 设置”里调大重连次数。
- 启用键盘驾驶时，空格键固定用于停止。
- 软件包由 GitHub Actions 在 Windows 上自动构建，并通过了启动自检。
